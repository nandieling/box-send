# BoxSend

## 功能介绍
本软件为批量转种软件。推荐盒子用户使用。有以下功能：

1. 输入源站种子链接后，一键批量转种并推送到下载器。
2. 分组功能。对于站点众多的用户，需要分批转种。因此做了分组功能，可以将站点进行分组，按组进行批量转种。
3. 站点限速。盒子发种最怕超速导致账号被ban。因此加入上传限速功能，默认上传限速10M/s，可手动调整。
4. PT-depiler gist和cookiecloud同步cookie。批量转种需要获取站点cookie。这两种方式可以互为补充，覆盖cookie同步功能需求。个别站点使用api key，需要自行手动输入。
5. 增加了几种主题和背景图片和透明度设置。

### 使用教程

1. 先去下载器窗口添加下载器地址、用户名、密码，并测试能否连通。
2. 在cookie窗口填入PT-depiler Gist同步和CookieCloud同步相关信息。这两个插件的使用方式，自行搜索。点立即同步测试是否同步成功。safari浏览器可以安装这两个插件：

```
https://github.com/nandieling/PT-depiler-safari  
https://github.com/nandieling/cookiecloud-safari

```
3. 站点分组窗口输入分组名称，点添加分组。在分组里添加站点，可批量添加。由于软件的cookie同步逻辑设置为添加到分组的站点才会同步，建议将转种源站单独放一个分组。调整上传限速。
4. 批量转种窗口，粘贴源站种子链接。勾选相应可选项。源站引用是在简介最上面增加转载自某站的说明。部分站点审核强制要求，建议勾选。选择转种分组，点开始运行。
